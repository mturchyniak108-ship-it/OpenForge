# Samsung S26 Ultra Worker

The S26 Ultra is the primary AI/orchestration node.

## Responsibilities

- Local AI inference
- LQL processing
- Prompt parsing
- Semantic planning
- Job creation
- Pipeline orchestration
- Capability selection
- Git coordination

## Delegation

When a job requires Blender or substantial rendering, create a declarative job for the Vivobook.

Do not duplicate Blender's implementation on the S26.

## Principle

The S26 describes the desired result.

The Vivobook realizes that result through Blender.
